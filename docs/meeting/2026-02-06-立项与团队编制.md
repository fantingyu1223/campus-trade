# 立项会议纪要：Agent 员工团队编制

- 日期：2026-02-06
- 参会：CEO（主持）
- 状态：已决策

## 议题

项目启动，确定 agent 员工团队编制与协同机制。

## 决策结论

1. **团队编制 7+1 岗**：产品经理（plan）、架构师（plan）、调研员（explore）、后端开发（coder）、前端开发（coder）、测试工程师 QA（coder）、运维工程师 DevOps（coder），文档员为兼任岗。编制映射到 Kimi Code 仅有的三种子代理类型（plan / explore / coder）。
2. **工作流**：需求分析 → 设计 → 开发 → 测试 → 交付 → 复盘，六阶段；PRD→设计→开发严格串行，前后端在接口契约冻结后并行。
3. **文档规范**：决策记 `docs/meeting/`、复盘记 `docs/review/`，新增 `docs/prd/`、`docs/design/`、`docs/qa/` 三个子目录，统一 `YYYY-MM-DD-主题.md` 命名。
4. **落地顺序**：DevOps+PM → 架构师+调研员 → 前后端 → QA → 文档员；每个角色在首次有真实任务时创建，不一次性全建。
