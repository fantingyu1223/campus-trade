## 同期记录的技术决策

1. **dev 启动方式固化**：`npm run dev`（ts-node）为本地唯一启动方式。
   生产构建（tsc）不重写 `@infra/*`、`@contract/*` 路径别名导致 `npm start`
   MODULE_NOT_FOUND，需接 `tsc-alias`，记为部署前置待办。
2. **JwtAuthGuard 挂载口径统一**：guard 写入 `req.user` 时除 `uid/role/school_id/status`
   外，补充 `id`（uid 别名）与 `identity_type`（DB 每请求装载），兼容
   product / product-status / wantbuy 三个 controller 的既有读取口径——
   该不一致曾导致发布等写操作 500。
3. **全局前缀豁免写法**：path-to-regexp 3.x 下 `admin/v1` 豁免需同时写
   `'admin/v1'` 与 `'admin/v1/(.*)'`（`*path` 为 6.x 语法、本项目不识别）。
4. **中文入库纪律**：mysql 客户端一律 `--default-character-set=utf8mb4`；
   git-bash `curl -d` 不内联中文（按 GBK 发出会乱码入库）。
