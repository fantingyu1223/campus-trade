# 设计规范 · 橙市（活力市集风）—— 小程序端定稿

> 版本：v1.0（定稿） · 日期：2026-10-08
> 来源：方案比稿 B（`docs/ui/proposals/scheme-b.html`）经评审选定，本文件为唯一事实源。
> 适用端：miniprogram（原生小程序 + WXSS）；落地映射见 `miniprogram/app.wxss` 的 `--ct-*` token。
> 基调：柿子橙高饱和点燃交易欲 + 校蓝撞色守住校园感，像周末跳蚤市场开集。文案与线上 PRD 一致。

## 2. 字体排印

- 字体族：系统默认（`-apple-system, 'PingFang SC', 'Helvetica Neue', sans-serif`），不引入外部字体。
- 字重仅 3 档：400 / 500 / 700（600 并入 700 使用，小程序端部分安卓机 600 渲染与 500 无差）。
- 价格等关键数字必须 `font-variant-numeric: tabular-nums`。

| 用途 | rpx | px@375 | 字重 | 行高 |
|---|---|---|---|---|
| 标签 / 角标 / 身份标 | 20 | 10 | 500–700 | 1.4 |
| 辅助说明 / 昵称 / 成色 | 22 | 11 | 400–500 | 1.5 |
| 次要正文 / 分类名 | 24 | 12 | 400–500 | 1.5 |
| 正文 / 搜索占位 / 描述 | 26 | 13 | 400 | 1.5 |
| 卡片标题 / 正文强调 | 28 | 14 | 700 | 1.4 |
| 小标题 / 底部按钮 | 30 | 15 | 700 | 1.3 |
| 区块标题（推荐闲置） | 34 | 17 | 700 | 1.3 |

## 3. 圆角 / 阴影 / 间距 token

### 圆角

| token | 值 | 用途 |
|---|---|---|
| `radius-card` | 28rpx / 14px | 商品卡、面板、分组卡（比旧版更圆润） |
| `radius-banner` | 24rpx / 12px | 安全提示条、提示块 |
| `radius-sm` | 12rpx / 6px | 输入框、小标签底 |
| `radius-pill` | 999px | 搜索框、FAB、急出标、筛选 tag、主按钮 |
| `radius-circle` | 50% | 分类图标、头像 |

### 阴影（浅而扩散，暖色投影，忌重黑）

| token | 值 | 用途 |
|---|---|---|
| `shadow-card` | `0 6rpx 20rpx rgba(178,88,42,0.08)` | 卡片 / 面板 |
| `shadow-fab` | `0 12rpx 32rpx rgba(255,90,45,0.38)` | FAB、底部主按钮 |
| `shadow-urgent` | `0 4rpx 12rpx rgba(216,30,63,0.35)` | 急出品红标 |

### 间距（8rpx 体系，全部为 8 的倍数）

`8 / 16 / 24 / 32 / 40 / 48`；页面左右边距 32rpx；卡片间距 24rpx；卡片内边距 24rpx；模块间距 32rpx。列表卡片一屏 4~6 张。

## 4. 组件六态要点

### 4.1 按钮（`.ct-btn`）
- default：主按钮橙 300→500 渐变 pill + `shadow-fab`，白字 ≥28rpx/700；ghost 按钮 `#F1EAE4` 底 + `#6B584C` 字。
- pressed：`scale(0.96) + opacity 0.9`，120ms ease-out（用 `hover-class` 实现，只动 transform/opacity）。
- disabled：`opacity 0.5` + 去阴影，禁止点击（`hover-class="none"`）。
- loading：文字变「…中」（如「提交中…」），维持主色底，禁止重复点击。
- empty / error：按钮本身无此二态；表单级错误在字段下方出品红 20rpx 提示。

### 4.2 商品卡片（`product-card`）
- default：白底、`radius-card`、`shadow-card`；急出为品红 pill + `shadow-urgent`；价格 `#D93E10` 38rpx/700 tabular-nums；成色 chip `#FFE4D6` 底 + `#D93E10` 字。
- pressed：`scale(0.96)`，120ms（`hover-class="product-card--press"`）。
- disabled：已售出 → 右上「已售」半透明黑标（沿用），整卡 `opacity 0.7`。
- loading：骨架屏（封面灰块 + 两行灰条呼吸，仅 opacity 动画 1200ms linear 循环）。
- empty：列表级空态文案（页面承接，非卡片职责）。
- error：列表级错误条 + 「点击重试」校蓝链接（页面承接）。

### 4.3 分类 chip（首页分类入口）
- default：50% 正圆图标底（五色 chip），下方 22rpx 分类名 `#6B584C`。
- pressed：`scale(0.92) + opacity 0.8`，120ms。
- 其余四态不适用（常启入口）。

### 4.4 搜索框
- default：白底 pill + 2rpx `#FF5A2D` 描边 + 实心橙「搜索」按钮。
- pressed（按钮）：`scale(0.93) + opacity 0.85`。
- focus：输入态保持描边（WXSS 不支持 :focus 伪类，聚焦态由「常显描边」策略代替，见 §7 偏差）。
- disabled / loading / empty / error：不适用；搜索无结果走列表空态文案。

### 4.5 tabBar（原生）
- default：未选 `#A08D80`；选中 `#D93E10`（原生 tabBar 文字约 20rpx，`#FF5A2D` 仅 3.3:1 不达标，故选 700 级，见 §7）。
- 原生 tabBar 不支持自定义图标缩放/指示条动效；如未来需要 spring 指示条，需改 custom-tab-bar（本期不做）。

### 4.6 FAB（发布悬浮按钮）
- default：橙 300→500 渐变 pill + `shadow-fab` + 白字 30rpx/700。
- pressed：`scale(0.92) + opacity 0.9`，120ms。
- 入场：spring 弹跳（见 §5）。
- disabled / empty / error：不适用；未登录点击走 `ensureLogin` 拦截（逻辑不变）。

## 5. 动效规范

**签名**：spring 微回弹 `cubic-bezier(0.34, 1.56, 0.64, 1)`；入场 ease-out `cubic-bezier(0.22, 1, 0.36, 1)`。仅 transform / opacity。单屏同时进行的动效 ≤ 3 个（入场编排算一组）。

| 元素 | 属性 | 时长 | 缓动 | 延迟 | 小程序落地方式 |
|---|---|---|---|---|---|
| 页面加载 · 各模块入场 | opacity + translateY(40rpx) + scale(0.97) | 360ms | spring | stagger 40ms/项（上限 240ms） | WXSS transition + `pageReady` 类切换（`onReady` 置位） |
| 商品列表入场 | 同上 | 360ms | spring | index × 40ms，封顶 240ms | 分批 setData：数据返回后置 `productsReady`，内联 `transition-delay` |
| 商品卡片按压 | scale(0.96) + opacity | 120ms | ease-out | 0 | `hover-class`，零 JS |
| 分类 chip 按压 | scale(0.92) + opacity 0.8 | 120ms | ease-out | 0 | `hover-class` |
| 按钮按压 | scale(0.93~0.96) + opacity | 120ms | ease-out | 0 | `hover-class="ct-press"` |
| FAB 入场 | scale(0.4→1) + opacity | 400ms | spring | 列表入场后 ~160ms | WXSS transition + `pageReady` 类 |
| tabBar 切换 | 原生切换 | — | — | — | 原生 tabBar 不可定制（见 §4.5/§7） |
| 骨架屏呼吸 | opacity 0.5↔1 | 1200ms | linear（仅呼吸/旋转允许 linear） | — | WXSS `@keyframes` |
| 滚动区入场（长列表可选） | opacity + translateY(40rpx) | 360ms | spring | 0 | `IntersectionObserver` 触发挂类（仅首屏外大量卡片时启用） |

> 复杂编排（多段串联）可用 `wx.createAnimation`，其 `timingFunction` 接受 cubic-bezier 四参；单段动效一律优先 WXSS transition，性能更好。

## 6. token 落地映射（miniprogram/app.wxss）

WXSS 支持 `page` 选择器上的 CSS 自定义属性，全局以 `--ct-*` 命名（ct = campus-trade）：

```
--ct-primary: #FF5A2D        --ct-primary-strong: #D93E10   --ct-primary-pressed: #B33209
--ct-primary-soft: #FFE4D6   --ct-primary-light: #FF7A45
--ct-accent: #2B5BFF         --ct-accent-strong: #1D46C8    --ct-accent-soft: #E0EBFF
--ct-urgent: #D81E3F         --ct-success: #2FA55C
--ct-bg: #FFF6EF             --ct-card: #FFFFFF             --ct-neutral-100: #F1EAE4
--ct-ink-900: #2B1D16        --ct-ink-600: #6B584C          --ct-ink-400: #A08D80
--ct-warn-bg: #FFF3C4        --ct-warn-line: #E8C44A        --ct-warn-text: #6E4E00
--ct-radius-card: 28rpx      --ct-radius-banner: 24rpx      --ct-radius-sm: 12rpx
--ct-shadow-card / --ct-shadow-fab / --ct-shadow-urgent
--ct-ease-spring: cubic-bezier(0.34,1.56,0.64,1)   --ct-ease-out: cubic-bezier(0.22,1,0.36,1)
```

全局复用类：`.ct-btn`（+`--primary/--ghost/--disabled`）、`.ct-card`、`.ct-tag`、`.ct-press`（hover-class 用）。

## 7. 与方案稿的偏差（落地约束）

1. **tabBar 选中色**：方案稿演示为亮橙，落地改 `#D93E10`——原生 tabBar 文字约 20rpx 小号字，`#FF5A2D`（3.3:1）不满足 AA 正文 4.5:1；且原生 tabBar 无法实现图标 spring 缩放与顶部指示条，需要时另立项 custom-tab-bar。
2. **输入框 focus 态**：WXSS 不支持 `:focus` 伪类，方案稿的聚焦描边改为「搜索框常显橙描边」策略；表单输入框维持 `#FFF6EF` 浅底，不另做聚焦环。
3. **商品封面比例**：组件 `product-card` 封面维持 320rpx 高（搜索页等复用方布局不受冲击），未采用方案稿的 150px 扁封面。
4. **FAB 渐变**：WXSS 支持 linear-gradient，正常落地；真机低端安卓注意阴影层数（FAB + 急出标两层暖色投影为上限）。
