## 二、启动步骤

### 1. MySQL（Docker）

```bash
# 镜像拉取：Docker Hub 直连超时，用 DaoCloud 镜像源
docker pull docker.m.daocloud.io/library/mysql:8.0
docker tag docker.m.daocloud.io/library/mysql:8.0 mysql:8.0

cd deploy && docker compose up -d        # 容器名 campus-trade-mysql
```

### 2. 数据库迁移 + 种子数据

```bash
cd server
npx prisma migrate deploy                 # 应用 0001_init（28 张表）

# 种子数据（school×1 / category×11 / user×2 / product×5 / admin×1）
# 注意：必须带 --default-character-set=utf8mb4，否则中文会双重编码入库
docker exec -i campus-trade-mysql mysql -uroot -pcampus123 \
  --default-character-set=utf8mb4 campus_trade < prisma/seed.sql
```

### 3. 后端（dev 模式，端口 3000）

```bash
cd server
cp .env.example .env   # 若不存在；关键项 DATABASE_URL / JWT_SECRET / WX_MOCK=true
npm run dev            # ts-node 直跑；注意：非 watch，改代码需重启
```

> **生产构建缺陷（遗留）**：`npm run build && npm start` 会因 tsc 不重写
> `@infra/*`、`@contract/*` 别名而 MODULE_NOT_FOUND。生产部署前需接入
> `tsc-alias`（或等效方案），本地开发不受影响。

### 4. 管理后台（端口 5173）

```bash
cd admin-web
npx vite --host 0.0.0.0 --port 5173
```

后台登录页尚未实现，token 用脚本签发后手动注入：

```bash
python scripts/sign-admin-token.py        # 默认 admin_id=1, role=admin, 7 天
# 浏览器打开 http://localhost:5173 后 F12 Console 执行：
#   localStorage.setItem('admin_token', '<上面输出的 token>')
# 刷新后访问 /governance/reports 等页面
```

### 5. 小程序

1. 微信开发者工具「导入项目」，目录选 `miniprogram/`（appid 用测试号即可）。
2. 「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
3. API 地址单点配置：`miniprogram/config.ts` 的 `API_BASE`
   - 模拟器：`http://localhost:3000/api/v1`
   - 真机预览：改成本机局域网 IP（手机与电脑同 WiFi），如 `http://192.168.0.100:3000/api/v1`
4. 编译后进入登录页，点微信登录即可（`WX_MOCK=true`，任意 code 即 openid）。

## 五、已知遗留

1. **生产构建别名缺陷**：`npm start` 不可用，需接 `tsc-alias`（见上文）。
2. **订单缺「标记交付」端点**：契约 #36 `POST /orders/{id}/complete-offline` 与
   #37 `GET /orders` 订单列表未实现，状态机 pending_delivery → pending_confirm
   没有 API 触发点；本次冒烟用 SQL 直接置位验证后续链路。需补任务。
3. **后台登录接口未实现**（§5.3 #51）：admin_user.password_hash 为占位值，
   当前用 `scripts/sign-admin-token.py` 签发 token。需补任务。
4. **契约口径不一致**：契约 #31 五态文案（pending_pay/paid…）与实现
   （PIM-SM-01 pending_delivery/pending_confirm…）不一致，待契约评审修正
   （任务清单批二遗留已记录）。
5. **图片本地位移**：COS 开通前图片 URL 仅为字符串存库，本地上传链路未做；
   占位图走 `/static/*`（main.ts `useStaticAssets`）。
6. **git-bash 注意**：在 git-bash 里用 `curl -d` 内联中文会按 GBK 发出导致
   乱码入库；含中文的联调请求请用 python/Postman 发送。mysql 客户端操作
   必须带 `--default-character-set=utf8mb4`。
