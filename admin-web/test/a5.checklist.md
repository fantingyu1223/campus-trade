# A5 高校名单配置页 · 联调清单（T-111）

- 页面：`/school`（名单列表）、`/school/join-requests`（加入申请审批）
- 追溯：@page A5 / @ac F36-AC2 / @module PIM-BC-06
- 契约：docs/design §5.3 school #68-73；PRD F36-AC2（docs/prd/2026-02-06-校园二手平台完整PRD.md §6.2 A5 行）

## 前置条件

- [ ] 后台服务已启动，`/admin/v1` 可达（vite dev proxy 或同源部署）
- [ ] localStorage 已写入 `admin_token`（登录页未做，手动占位；未写时请求不带 Authorization，应收到 1001 并提示）

## 一、名单列表页 `/school`（#68）

### 页面元素
- [ ] 卡片标题「高校名单（首期=本校）」+ 右上角「新增学校」按钮
- [ ] 筛选栏：学校名称关键字输入框、状态下拉（生效中/待开通/已停用/全部）、查询按钮
- [ ] 表格列：ID / 学校名称 / 邮箱后缀 / 在册成员数 / 状态 el-tag / 操作（编辑、停用）
- [ ] 底部分页组件，显示 total

### 操作流程与验收点
- [ ] 首期数据：列表仅含本校一条，状态 tag 绿色「生效中」（F36 首期名单=本校单校）
- [ ] 关键字搜索 + 回车/点查询：请求带 `keyword`，列表正确过滤，页码重置为 1
- [ ] 状态筛选切换：请求带 `status`(active/pending/offboarded)
- [ ] 加载中显示 v-loading；接口失败时 ElMessage 错误提示；空数据显示「暂无学校」空态文案
- [ ] 翻页：page 参数变化并重新请求

## 二、新增学校对话框（#69，F36-AC2 验证配置通道）

- [ ] 点击「新增学校」弹出 el-dialog，含名称/邮箱后缀/备注三个字段
- [ ] 名称为空、后缀为空或格式非法（非 `@xxx.edu.cn` 形式）时表单校验拦截，不发请求
- [ ] 填合法数据保存：POST `/admin/v1/schools`，成功提示「新增成功，认证页学校列表将同步展示」，列表刷新出现新校
- [ ] 域名重复（错误码 1002）：展示后端 message 错误提示，不关闭对话框
- [ ] 对话框关闭后表单被重置（再次打开无残留）
- [ ] **F36-AC2 端到端**：新增成功后，用户端认证页学校列表同步展示该校（跨端联调项，首期不启用新增，仅验证通道）

## 三、编辑学校（#70）

- [ ] 点「编辑」对话框回填名称/后缀/备注，保存走 PUT `/admin/v1/schools/{id}`，成功后列表刷新

## 四、停用学校（#71）

- [ ] 点「停用」弹出确认框，文案含学校名；member_count>0 时追加提示「该校当前有 N 名在册成员，需先处置」
- [ ] 确认框点「取消」不发请求
- [ ] 确认停用：DELETE `/admin/v1/schools/{id}`（body `{confirm:true}`），成功提示「已停用」，该行状态变「已停用」且停用按钮消失
- [ ] 存在在册成员（错误码 4002）：展示后端 message，列表状态不变
- [ ] 已停用（offboarded）行不显示「停用」按钮

## 五、加入申请审批页 `/school/join-requests`（#72/#73）

### 页面元素
- [ ] el-tabs：待审批 / 已通过 / 已拒绝，默认待审批
- [ ] 表格列：ID / 申请学校 / 联系方式 / 申请说明（溢出省略）/ 提交时间 / 状态 tag / 操作
- [ ] 待审批行操作列显示「通过」「拒绝」；已处理行显示灰字「已处理」

### 操作流程与验收点
- [ ] 切 tab：请求带对应 `status` 参数，页码重置
- [ ] 通过：弹窗显示黄色警示「通过后系统将自动创建该校并开通（首期名单收窄为本校…）」，备注选填；确认后 POST `.../handle` `{action:'approve'}`，提示「已通过，学校已自动创建并开通」
- [ ] 拒绝：弹窗要求填拒绝原因，**原因为空时前端拦截不发请求**；确认后 `{action:'reject', note}`，提示「已拒绝」
- [ ] 审批成功后列表刷新，该申请从「待审批」消失、出现在对应 tab
- [ ] 重复审批/状态冲突（4002）：展示后端 message 错误提示
- [ ] **联动验证**：approve 后回 `/school` 名单列表可见自动创建的新校（#73 契约约定 approve 自动建校并开通）

## 六、通用

- [ ] 所有请求头带 `Authorization: Bearer <token>`（token 来自 localStorage `admin_token`）
- [ ] 业务判定以响应包络 `code===0` 为准，失败展示 `message`
- [ ] 侧边导航「平台配置」下可进入两个页面，面包屑与路由 meta.title 一致
