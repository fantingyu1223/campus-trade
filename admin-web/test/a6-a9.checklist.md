## A6 账号管理（/governance/accounts）

**页面元素**

- 顶部筛选栏：keyword 输入框（昵称/账号模糊检索）、status 状态下拉、role 角色下拉、查询/重置按钮
- 账号列表表格：账号、昵称、角色、状态（el-tag）、注册时间、操作列（详情 / 封禁 / 解封）
- 状态 tag：normal（绿色）/ banned（红色）/ deactivating（橙色，注销中）
- 封禁对话框：duration_days 输入（-1 表示永久封禁）、reason 必填输入、确认/取消
- 解封操作：ElMessageBox confirm 二次确认
- 详情抽屉：账号基础信息、统计区（发布数/订单数/被举报数等）、处置留痕列表

**操作步骤**

1. 输入 keyword（如昵称片段），点击查询，观察列表过滤
2. 分别切换 status / role 筛选，组合 keyword 再查
3. 对 normal 账号点「封禁」：reason 留空点确认（应校验拦截）；填 duration_days=-1 + reason 后确认
4. 对 banned 账号点「解封」，在 confirm 弹窗中分别测试「取消」与「确定」
5. 点「详情」打开抽屉，查看统计区与留痕列表

**验收点**

- [ ] keyword 检索命中昵称/账号模糊匹配，空 keyword 查询返回全量
- [ ] status / role 筛选生效，可与 keyword 组合，重置按钮清空全部条件
- [ ] normal / banned / deactivating 三种状态 tag 颜色与文案正确
- [ ] 封禁表单 reason 为空时校验提示且不提交
- [ ] duration_days=-1 提交后账号变 banned，留痕记录「永久封禁」语义正确
- [ ] 解封必须经 confirm 确认，取消不产生请求，确认后状态变 normal
- [ ] 详情抽屉统计字段与契约 DTO 一致，无 undefined/NaN 渲染
- [ ] 留痕列表按时间倒序，含操作人/动作/reason/时间
- [ ] 空列表有空态提示；接口失败有错误提示且页面不白屏

## A8 申诉仲裁（/governance/appeals）

**页面元素**

- 筛选栏：类型（dispute 纠纷申诉 / punishment 处罚申诉）、状态下拉
- 申诉列表：申诉编号、类型、关联单号、提交时间、48h 介入时限倒计时、状态、操作（裁决）
- 倒计时单元格：剩余时间实时显示，**超时（<0）标红**
- 裁决对话框：result 四枚举单选、note 必填 textarea、关联处置 linked_action 可选下拉
- 详情区：证据图（点击预览大图）、关联上下文卡（关联订单/举报/处罚摘要）

**操作步骤**

1. 切换类型/状态筛选，确认列表过滤
2. 找一条临近/超过 48h 的申诉，观察倒计时标红
3. 打开裁决对话框：note 留空点确认（应拦截）；依次选择四种 result 提交
4. 裁决时分别测试「不选关联处置」与「选择关联处置」两种提交
5. 点击证据图预览；查看关联上下文卡跳转/展示

**验收点**

- [ ] 48h 倒计时按 `intervene_deadline` 正确计算，超时记录倒计时标红
- [ ] result 四枚举选项齐全，与契约枚举值一致（不落自定义值）
- [ ] note 为空时表单校验拦截，不得提交
- [ ] linked_action 可选：不选时请求体不传该字段（非空字符串），选择时按枚举传值
- [ ] 裁决成功后列表状态刷新为 done，不可重复裁决
- [ ] 证据图可点击预览大图，多图可切换；无证据图时有占位提示
- [ ] 关联上下文卡展示关联单摘要（订单号/举报号/处罚记录），字段与契约一致
- [ ] 接口失败/空列表有对应错误态与空态

## A9 词表配置（/governance/word-list）

**页面元素**

- 词表列表表格：词条、类别、状态（启用/停用）、更新时间、操作（编辑/停用或启用/删除）
- 新增/编辑对话框：表单校验（词条必填、去重提示、类别必选）
- 停用/启用：switch 或按钮 + confirm 二次确认
- 保存成功提示：含「保存后自动刷新词表快照」文案
- 变更历史侧栏：操作人、动作（新增/编辑/停用/启用/删除）、词条快照、时间

**操作步骤**

1. 新增词条：必填项留空测试校验；填完整提交，观察成功提示文案
2. 编辑已有词条，修改类别/词面后保存
3. 对启用词条执行停用，confirm 取消一次、确认一次；再启用恢复
4. 删除一条词条（如有删除入口），confirm 确认
5. 打开变更历史侧栏，核对每次操作均留痕

**验收点**

- [ ] 新增/编辑表单必填校验生效，重复词条有提示（前端或后端 409 均可，需有用户可读反馈）
- [ ] 停用/启用均有 confirm 二次确认，取消不发请求
- [ ] 每次保存成功提示含「保存后自动刷新词表快照」文案
- [ ] 保存/停用/删除后列表自动刷新，状态 tag 即时更新
- [ ] 变更历史侧栏覆盖全部动作类型，按时间倒序，含操作人与变更前后值
- [ ] 空词表/接口失败有空态与错误态
