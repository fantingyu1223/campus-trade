# A2-A7 治理页联调清单

> 接口契约：docs/design §5.3 #54-56（举报）、#59-60（黄牛预警）、#61-64（商家入驻审核）
> 前端实现：src/views/governance/（ReportQueue / ReportDisposal / MerchantReview / RiskReview）

## A2 举报队列（ReportQueue.vue，#54）

- [ ] 超时行红色标红：`sla_overdue=true` 或倒计时 ≤0 的行带 `row-timeout` 红色背景，并显示红色 el-tag「超时」
- [ ] target_type 前端筛选：契约 #54 仅支持 status+分页，「对象类型」为当前页前端过滤（换筛选不触发请求）
- [ ] status 查询筛选：切换状态下拉触发 `GET /admin/v1/reports?status=xxx`（空值不传参）
- [ ] 倒计时秒级刷新：SLA 倒计时列每秒重算（setInterval 1s 更新 nowTick），格式 `Xh Ym`，≤0 显示「已超时」
- [ ] 行点击跳转 `/governance/reports/{id}`

## A3 举报处置（ReportDisposal.vue，#55/#56）

- [ ] result 仅枚举四项（off_shelf 下架 / warning 警告 / ban 封禁 / rejected 驳回），el-select 禁用输入，不可自由文本
- [ ] result=ban 时显示 duration_days（el-input-number，min=1），未填或 <1 阻止提交并提示
- [ ] 提交前 ElMessageBox.confirm 二次确认，取消不发请求；确认后 POST #56，成功 ElMessage.success + 返回上一页
- [ ] 留痕 timeline：#55 返回的 timeline 以 el-timeline 展示（时间/操作人/动作/备注）
- [ ] target_snapshot 以 JSON pre 展示；evidence_urls 以 el-image 组展示并支持点击预览

## A4 商家入驻审核（MerchantReview.vue，#61-64）

- [ ] 打开详情抽屉调 #62，成功返回后提示 ElMessage.info「本次调阅已留痕」
- [ ] 驳回理由 reason_code 八项枚举（1 证件模糊/2 证件过期/3 信息不符/4 非本校学生/5 材料缺失/6 疑似伪造/7 在禁入驻名单/8 其他），仅可选不可输入
- [ ] reason_code=8（其他）时 note 必填校验（空值阻止提交并提示）
- [ ] 2 个工作日倒计时：列表 SLA 列按 sla_deadline 秒级刷新，超时显示「已超时」+ 红色 el-tag「超时」
- [ ] 通过按钮 ElMessageBox.confirm 后调 #63；驳回确认后调 #64；成功后关闭抽屉并刷新列表

## A7 黄牛预警复核（RiskReview.vue，#59/#60）

- [ ] 「确认」弹窗三选映射：转商家入驻线索→`{conclusion:'limit_publish'}`；转处置-警告→`{conclusion:'action',action_detail:'warning'}`；转处置-封禁→`{conclusion:'action',action_detail:'ban'}`
- [ ] 「忽略」：ElMessageBox.confirm 后提交 `{conclusion:'release'}`
- [ ] 状态 tag：pending→warning「待复核」；confirmed→success「已确认」；false_alarm→info「误报」
- [ ] 复核成功后刷新列表，状态列更新

## 契约偏差提示（联调需后端确认）

1. #54 列表契约未声明 created_at/status，页面按可选字段渲染，缺失时显示「—」
2. #60 无「转商家入驻线索」独立枚举，暂映射 limit_publish（§4.25 表注）
3. #64 reason_code 为数值 1-8（与 types/contract.ts 字符串枚举口径冲突，按 #64 接口表实现）
4. A7 状态 tag 含 confirmed/false_alarm，但 #59 契约 status 枚举为 pending/handled；前端对未识别状态兜底原文展示
