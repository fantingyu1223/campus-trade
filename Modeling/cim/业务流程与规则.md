## 第一部分 核心业务流程（CIM-P-01 ~ CIM-P-05）

### CIM-P-01 发布商品流程

- **参与者**：卖家（学生/教职工/商家）
- **业务目标**：卖家把闲置物品以真实、合规的信息上架，供买家浏览购买。
- **来源**：F5、F22、F10a、N3、N7、§4.4 卖家旅程阶段②

```mermaid
flowchart TD
    A([卖家想出售闲置物品]) --> B{已完成身份认证?}
    B -- 否 --> B1[引导先完成身份认证] --> B
    B -- 是 --> C[拍摄实物照片]
    C --> D[填写标题、品类、成色、价格、自提地点与可约时间、描述]
    D --> E[声明交易方式意向：当面自提/线上支付/两者皆可]
    E --> F{需要急出曝光?}
    F -- 是 --> G{急出额度未满3件?}
    G -- 否 --> G1[提示已达上限，不可打急出标] --> H
    G -- 是 --> H[确认发布]
    F -- 否 --> H
    H --> I{内容合规检查：实拍图齐备、字段完整、无违禁品与违规词}
    I -- 不合规 --> I1[逐项提示缺失或违规原因，退回修改] --> D
    I -- 合规 --> J([商品上架，可被浏览搜索咨询])
```

- **关键规则引用**：CIM-R-01（未认证不可发布）、CIM-R-05（3 步发布）、CIM-R-06（实拍图与成色强制）、CIM-R-07（正面清单）、CIM-R-08（违禁拦截）、CIM-R-09（急出 3 件上限）。

### CIM-P-02 购买流程（当面自提 / 线上支付双分支）

- **参与者**：买家、卖家
- **业务目标**：双方协商一致并完成实物交接与货款交割，交易体面闭环。
- **来源**：F34、F7、F12、F13、F14、Q1/Q6、§4.2 场景四、§4.3 买家旅程③④

```mermaid
flowchart TD
    A([买家看中在售商品]) --> B[买家向卖家发起会话]
    B --> C[双方答疑议价，协商交易方式、时间与地点]
    C --> D{协商确定哪种交易方式?}
    D -- 当面自提 --> E1[双方按约定时间地点见面交接]
    E1 --> E2[买家现场验货]
    E2 --> E3{验货满意?}
    E3 -- 否 --> E4[交易不成立，双方各自离开，商品仍在售]
    E3 -- 是 --> E5[买家线下付款给卖家]
    E5 --> E6[卖家将商品标记已售并指定该买家]
    E6 --> Z([交易完成，双方获得互评资格])
    D -- 线上支付 --> F1[买家阅读风险明示：平台不托管资金、务必当面验货后再确认收货、取消与拒收规则、平台可协调但无法强制退款]
    F1 --> F2[买家确认知悉并付款]
    F2 --> F3[商品被锁定为交易中，其他买家不可再付款，订单进入待交货]
    F3 --> F4[双方按约定时间地点当面交货，买家现场验货]
    F4 --> F5{验货满意?}
    F5 -- 是 --> F6[买家现场确认收货]
    F6 --> Z
    F5 -- 否 --> G[现场拒收或事后取消，进入 CIM-P-03]
    F4 -. 超过约定时间48小时买家未确认且无异议 .-> F7[超时视为自动确认收货] --> Z
```

- **关键规则引用**：CIM-R-10（付款前强制风险明示）、CIM-R-11（付款锁商品防超卖）、CIM-R-12（48h 超时自动确认）、CIM-R-13（标记已售强制指定买家）、CIM-R-14（意向声明不强制约束现场分歧）、CIM-R-04（会话发起边界）。

### CIM-P-03 取消 / 拒收流程

- **参与者**：买家、卖家（共同边界：买家确认收货之前）
- **业务目标**：任一方在交易完成前体面退出，货款原路退回，商品回到可售状态。
- **来源**：F35、§10.2 口径确认 1、裁决 3/4、US-12

```mermaid
flowchart TD
    A([线上支付订单处于未确认收货状态]) --> B{退出情形}
    B -- 远程反悔/协商退出：任一方发起取消 --> C1[向对方发出取消请求]
    C1 --> C2{对方24小时内是否响应?}
    C2 -- 对方同意 --> D[取消成立]
    C2 -- 24小时未响应 --> C3[视为默认同意] --> D
    C2 -- 对方拒绝 --> C4[取消不成立，订单回到原状态并留痕，交易继续] --> Z2([流程结束])
    B -- 当面交货现场验货不满意：买家现场拒收 --> D1[买家当场声明拒收并说明理由，留时间记录]
    D1 --> D
    D --> E[货款按原路退回买家，平台不经手资金]
    E --> F[商品自动恢复上架，卖家可再下架]
    F --> Z1([订单关闭：已取消])
    A -. 买家已确认收货 .-> G[不可取消，售后异议引导走申诉 CIM-P-05]
```

- **关键规则引用**：CIM-R-15（24h 默认同意，双向同规则）、CIM-R-16（原路退款、平台不经手资金）、CIM-R-17（取消成功商品恢复上架）、CIM-R-18（已确认收货不可取消）、CIM-R-19（拒收必须现场留痕）。

### CIM-P-04 举报与处置流程

- **参与者**：举报人（用户）、运营人员、被举报方
- **业务目标**：违规行为被及时发现、按时限处置、结果闭环通知，举报人全程匿名。
- **来源**：F18、F20、F21、N2/N3/N6、§4.5 边缘旅程一

```mermaid
flowchart TD
    A([用户发现违规：商品/用户/商家/聊天内容]) --> B[发起举报：选择类型（诈骗/违禁品/虚假描述/其他），附说明与截图]
    B --> C[举报受理，举报人收到受理回执]
    C --> D{按类型分级处理时限}
    D -- 诈骗类：4小时内 --> E[运营核查举报内容与证据]
    D -- 违禁品类：24小时内 --> E
    D -- 普通类：48小时内 --> E
    E --> F{举报是否成立?}
    F -- 不成立 --> G[驳回举报] --> H
    F -- 成立 --> I{被举报对象与情节}
    I -- 商品违规 --> J1[商品下架]
    I -- 用户违规 --> J2[警告或封禁账号]
    I -- 商家发布违禁品：加重处置 --> J3[商品立即下架 + 撤销商家资质 + 列入禁入驻名单]
    J1 --> H
    J2 --> H
    J3 --> H
    H[处理结果通知举报人，处置结果通知被处置方并告知申诉入口]
    H --> K([流程结束；被处置方7天内可申诉，衔接申诉救济（CIM-R-24/R-31），无独立申诉 CIM 流程])
    D -. 超时未处理 .-> L[队列标记超时告警，供运营管理与考核] --> E
```

- **关键规则引用**：CIM-R-20（举报人匿名保护）、CIM-R-21（分级处理时限 4/24/48h）、CIM-R-22（处理结果四枚举）、CIM-R-23（商家违禁品加重处置三件套）、CIM-R-24（处置后 7 天申诉权）。

### CIM-P-05 商家入驻审核流程

- **参与者**：商家申请人、运营人员
- **业务目标**：经营主体资质真实合规后方可入驻经营，审核过程透明、时限明确、驳回可救济。
- **来源**：F32、F33、§8.5、裁决 9、§4.5 边缘旅程三

```mermaid
flowchart TD
    A([经营主体希望入驻经营]) --> B[提交门店信息与资质材料：营业执照/校园门店证明]
    B --> C{材料完整?}
    C -- 否 --> C1[提示补全材料，不计时] --> B
    C -- 是 --> D[申请进入审核队列，2个工作日时限开始计时（跳过周末与法定节假日）]
    D --> E[运营人工审核资质]
    E --> F{审核结论}
    F -- 通过 --> G[申请人获得认证商家身份与全链路强制展示标识]
    G --> Z1([入驻成功，可以商家身份发布经营])
    F -- 驳回 --> H[驳回通知必须包含具体理由（限驳回理由枚举），不得空理由]
    H --> I[进入7天冷却期，期间不可重新提交]
    I --> J{申请人意向}
    J -- 补正再申请（不限次数） --> B2[提交补正材料，时限重新计时] --> D
    J -- 不服驳回 --> K[发起申诉救济：衔接举报处置后的申诉通道（CIM-R-24/R-31），不存在独立申诉 CIM 流程] --> L[运营复核并给出结论] --> Z2([流程结束])
    D -. 超过2个工作日未处理 .-> M[申请标记超时，供运营管理与考核] --> E
```

- **关键规则引用**：CIM-R-25（2 个工作日 SLA 计时口径）、CIM-R-26（驳回必给理由枚举）、CIM-R-27（7 天冷却不限次补正）、CIM-R-28（商家全链路强制亮标）、CIM-R-23（造假/违禁转入加重处置与禁入驻名单）。
