# U1-U4 登录/认证/首页链路 联调清单

> 追溯：PRD §6.1 U1-U4、F1-AC1/AC2/AC3、F36-AC1、F13-AC3；API 契约 docs/design §5.2 auth/school 分组（#1-#6）。
> 联调前置：baseURL 占位 `https://api.example.com/api/v1`，需替换为真实环境并在小程序后台配置合法域名（开发期可在开发者工具勾选"不校验合法域名"）。

## U2 登录页（pages/login/login）

| # | 元素/操作 | 验收点 |
|---|---|---|
| U2-1 | 微信授权登录按钮 | 页面展示授权按钮；点击触发 wx.login → POST `/auth/wx-login`（body 仅含 code），返回 `token/refresh_token/user` 写入 storage |
| U2-2 | 协议勾选 | 未勾选《用户协议》《隐私政策》直接点登录 → 拦截并 toast「请先勾选并同意用户协议与隐私政策」，不发起登录请求 |
| U2-3 | 登录成功分流 | `user.verified=true` → reLaunch 至 U1 首页；`verified=false` → redirect 至 U3 认证页（F1-AC1） |
| U2-4 | 登录失败 | 接口返回非 0 code / 网络异常 → toast 错误信息，按钮恢复可点（无 loading 卡死） |
| U2-5 | 游客入口 | 「暂不登录，先逛逛」→ 进入首页，浏览不受限（N1） |

## U3 身份认证页（pages/verify/verify）

| # | 元素/操作 | 验收点 |
|---|---|---|
| U3-1 | 身份 Tab | 学生/教职工/商家三类可切换，表单随 Tab 切换 |
| U3-2 | 学校列表 | 进入页面请求 GET `/schools`，列表展示 name/city；加载中有加载态、失败有错误态+重试、空列表有空态 |
| U3-3 | 学校搜索 | 输入关键词触发列表刷新；选中学校高亮回填 |
| U3-4 | 名单外申请加入（F36-AC1） | 搜索名单外学校无结果 → 显示「该校暂不支持」卡片 + 申请加入表单；提交 POST `/schools/join` 成功 toast 后收起 |
| U3-5 | 学生表单校验 | 学号/校园邮箱两种方式切换；姓名/学号为空、邮箱格式错误 → 逐项拦截提示，不提交 |
| U3-6 | 教职工表单 | 工号+校园邮箱必填校验；提交 `type=teacher` |
| U3-7 | 学生认证提交（F1-AC1） | POST `/auth/verify`，成功后跳转 U4 `?status=pending` |
| U3-8 | 非本校拒认（F1-AC3） | 服务端返回 1006 → toast「该校暂不支持」并展开申请加入入口 |
| U3-9 | 商家占位 | 材料上传占位（chooseMedia 最多 3 张本地预览）；提交按钮引导入驻申请（U5 待接入提示） |

## U4 认证结果页（pages/verify-result/verify-result）

| # | 元素/操作 | 验收点 |
|---|---|---|
| U4-1 | 状态拉取 | onShow 调 GET `/auth/verify/status`；加载态/查询失败错误态+「重新查询」可用 |
| U4-2 | pending 态 | 展示「认证审核中」+ 刷新状态按钮 |
| U4-3 | approved 态 | 展示「认证通过」；本地用户快照 verified 回写 true；「去逛逛」进入首页 |
| U4-4 | rejected 态 | 展示「认证未通过」+ `reject_reason`；「重新认证」重试入口回 U3 |
| U4-5 | 带参直达 | U3 提交后带 `?status=pending` 直达，先展示 pending 再按拉取结果刷新 |

## U1 首页（pages/index/index）

| # | 元素/操作 | 验收点 |
|---|---|---|
| U1-1 | 常驻安全提示条（F13-AC3） | 页面顶部 safety-banner 常驻可见，文案含"平台不托管资金/当面验货"口径 |
| U1-2 | 分类入口 | 8 个静态品类占位 grid 展示；点击有反馈（U7 待接入提示） |
| U1-3 | 商品流 | 卡片含标题/价格/成色/急出标/卖家昵称+身份标识（identity-badge）；加载/错误/空三态可用 |
| U1-4 | 身份标识 | merchant 显示金色「认证商家」与个人身份视觉可区分（F33-AC1）；student/staff 蓝色标识 |
| U1-5 | 搜索框 | 输入可回填，确认/点按钮有反馈（U7 待接入提示） |
| U1-6 | 商品卡片点击 | 有反馈（U8 待接入提示） |

## 公共能力

| # | 项 | 验收点 |
|---|---|---|
| C-1 | utils/session.ts | `login()` 完成 code 换 token 并写 storage；`getToken()` 读写正确；`ensureLogin()` 未登录跳 U2 并 reject（F1-AC2 受限操作前置） |
| C-2 | request 封装 | 自动注入 `Authorization: Bearer`；响应包络 `code=0` 才 resolve；1001/1002 清除登录态并跳 U2 |
| C-3 | 契约一致性 | 所有请求/响应字段与 §5.2 #1-#6 一致，无自创字段（school_id/type/evidence 等命名一致） |
