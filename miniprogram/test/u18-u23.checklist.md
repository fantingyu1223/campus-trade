# U18–U23 联调清单（test/u18-u23.checklist.md）

> 适用范围：评价提交、求购列表与发布、通知中心、收藏页。
> 前置：app.json 已注册 5 个新页面；Mock 模式（USE_MOCK=true）可自测，接口就绪后置 false 复测一遍。
> 每条验收点通过后勾选 `[x]`。

## U18 评价提交页（pages/review-submit/review-submit）

### 页面元素
- 订单信息摘要（商品图、标题、价格）
- 1–5 星点选组件（星级为必填）
- 文本域 + 实时字数计数器（上限 500 字）
- 「延迟公开」提示卡（说明评价在双方互评或 7 天后公开）
- 底部提交按钮

### 操作步骤
1. 从订单详情页带 `orderId` 进入本页。
2. 不选星级直接点提交 → 按钮禁用/给出提示。
3. 点选 4 星，输入评价文本，观察计数器随输入变化。
4. 输入超过 500 字 → 输入被截断，计数器停在 500/500。
5. 点击提交。

### 验收点
- [ ] 星级可点选，选中态与未选中态视觉区分明显
- [ ] 字数计数器实时更新，格式为 `当前/500`
- [ ] 超过 500 字被截断，不报错
- [ ] 延迟公开提示卡常驻展示，文案与契约一致
- [ ] 未选星级时提交按钮禁用（或点击给出明确提示），不会发起请求
- [ ] 提交成功后页面进入「已提交待公开」状态，不再可编辑/重复提交
- [ ] 提交失败时展示错误提示并可重试

## U19 求购列表（pages/want-buy/want-buy）

### 页面元素
- 顶部 Tab：「全部」/「我的」
- want-buy-card 条目（标题、期望价位、剩余时间倒计时、状态）
- 卡片操作区：续期 / 关闭 / 标记已买到
- 空态视图

### 操作步骤
1. 进入页面，默认「全部」Tab，核对列表数据与接口返回一致。
2. 切换「我的」Tab，列表只展示本人发布的求购。
3. 在「我的」条目上点「续期」→ 弹出 confirm，确认后查看倒计时是否 +30 天并刷新。
4. 点「关闭」或「已买到」→ 条目置灰，操作按钮隐藏。
5. 构造/等待剩余 ≤3 天的条目，检查倒计时变红并带「即将到期」标记。
6. 在无数据状态下检查空态。

### 验收点
- [ ] 「全部/我的」Tab 切换正常，数据隔离正确
- [ ] want-buy-card 元素完整：标题、价位、倒计时、状态
- [ ] 续期需 confirm 二次确认；确认后剩余时间 +30 天，倒计时立即刷新
- [ ] 关闭 / 已买到后条目置灰，操作按钮隐藏，不可再次操作
- [ ] 剩余 ≤3 天时倒计时红色显示「即将到期」
- [ ] 列表为空时展示空态文案/插图，无报错

## U19 求购发布页（pages/want-buy-publish/want-buy-publish）

### 页面元素
- 标题、描述（必填）
- 期望价位 min / max 输入框
- 有效期「30 天」提示条
- 提交按钮

### 操作步骤
1. 留空必填项直接提交 → 表单逐项标红/提示。
2. min 填 100、max 填 50 → 提交，检查价位校验。
3. 修正为 min ≤ max，提交成功并返回列表，新条目出现在「我的」Tab。

### 验收点
- [ ] 必填项缺失时禁止提交并给出明确提示
- [ ] 价位 min > max 时校验拦截，提示文案清晰
- [ ] 页面常驻「有效期 30 天」提示条
- [ ] 提交成功后跳转/返回列表并能看到新条目

## U22 通知中心（pages/notification/notification）

### 页面元素
- 通知列表，条目含五类类型图标（want_buy_match / order_status / want_buy_expire / review_remind / 系统公告）
- 未读圆点 + 未读计数（顶部/TabBar）
- 「全部已读」按钮
- 空态视图

### 操作步骤
1. 进入页面，核对各类通知图标与类型一一对应。
2. 查看未读圆点与未读计数是否一致。
3. 分别点击四种业务类型通知，确认标记已读且跳转正确页面。
4. 点击「全部已读」，圆点与计数清零。
5. 无通知时检查空态。

### 验收点
- [ ] 五类通知各有对应图标，类型不串
- [ ] 未读条目显示圆点，未读计数与实际未读条数一致
- [ ] 单条点击后标记已读（圆点消失、计数 -1）并按类型跳转：
  - [ ] want_buy_match → 商品详情
  - [ ] order_status → 订单详情
  - [ ] want_buy_expire → 求购页
  - [ ] review_remind → 评价页
- [ ] 「全部已读」后圆点与计数全部清零
- [ ] 空态展示正常

## U23 收藏页（pages/favorites/favorites）

### 页面元素
- 收藏列表（封面、标题、当前价）
- 价格变动标识：「已降价↓」绿色 /「已涨价↑」红色
- 状态灰标：已售出 / 已下架
- 长按取消收藏（confirm）
- 空态视图

### 操作步骤
1. 进入页面，核对当前价低于收藏时价的条目显示绿色「已降价↓」，高于则红色「已涨价↑」。
2. 检查 sold / off_shelf 条目带对应灰标且视觉置灰。
3. 长按某条目 → confirm 确认后条目从列表移除。
4. 全部取消后检查空态。

### 验收点
- [ ] 降价显示绿色「已降价↓」，涨价显示红色「已涨价↑」，与契约 fav_price 对比逻辑一致
- [ ] 已售出 / 已下架条目有灰标且整体置灰，不可误操作
- [ ] 长按触发取消收藏，需 confirm 二次确认，确认后即时移除
- [ ] 空态展示正常，无报错
