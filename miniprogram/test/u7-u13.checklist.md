## U7 搜索页（pages/search/search）

### 筛选面板

**页面元素**：筛选按钮、筛选面板（价格区间 min/max 输入、成色五档单选、卖家身份过滤、排序三种）。

**操作步骤**：
1. 首页点击进入搜索页，输入关键词搜索；
2. 点击「筛选」打开面板；
3. 分别设置价格区间、成色档位、身份过滤、排序方式，点击「确定/应用」；
4. 点击「重置」清空筛选。

**验收点**：
- [ ] 价格区间输入 min/max 后结果按区间过滤，min > max 时有提示且不发起请求
- [ ] 成色五档（全新/几乎全新/九成新/八成新/较旧）单选生效，再次点击可取消
- [ ] 身份过滤（如仅看学生认证卖家）生效，筛选条件回显在面板中
- [ ] 排序三种（综合/最新/价格）切换后列表顺序正确变化
- [ ] 重置后所有筛选清空并重新请求默认列表
- [ ] 面板打开/关闭有遮罩，点击遮罩可关闭

### 急出标与空态

**页面元素**：列表卡片「急出」角标、空态组件（无结果插图 + 提示文案 + 返回/换关键词入口）。

**操作步骤**：
1. 搜索含急出商品的关键词；
2. 搜索一个无结果的关键词。

**验收点**：
- [ ] `urgent=true` 商品卡片显示「急出」标识，样式醒目
- [ ] 无结果时展示空态文案与引导操作，不报错、不白屏
- [ ] 加载中有 loading 态，请求失败有错误态与重试入口

## U8 商品详情页（pages/product-detail/product-detail）

**页面元素**：顶部图集 swiper、商品信息区、卖家信息条（含身份标识）、sold 全屏遮罩、安全提示文本、底部「联系卖家」按钮。

**操作步骤**：
1. 从搜索/列表点击在售商品进入详情；
2. 滑动图集查看多图；
3. 查看卖家信息条与安全提示；
4. 进入一个 status==='sold' 的商品详情；
5. 点击「联系卖家」。

**验收点**：
- [ ] 图集可左右滑动，多图显示页码/指示点，单图正常铺满
- [ ] 卖家信息条展示昵称与身份标识（学生认证/未认证等，按契约 role/verify 字段渲染）
- [ ] status==='sold' 时全屏「已售出」遮罩覆盖，购买/联系操作被禁用或拦截
- [ ] 页面底部/交易区展示安全提示文本（如「请勿脱离平台交易」）
- [ ] 点击「联系卖家」为占位实现（toast/跳转占位），不报错
- [ ] 商品不存在/加载失败展示错误态

## U10 发布页（pages/publish/publish）

**页面元素**：三步步骤条（填写信息 → 上传图片 → 确认发布）、图片上传区（≤9 张）、表单字段（标题/描述/价格/成色/分类/交易方式）、急出开关、提交按钮。

**操作步骤**：
1. 进入发布页，确认步骤条初始为第 1 步；
2. 留空必填项直接「下一步/提交」，观察逐项红字提示；
3. 补齐表单，上传图片（尝试上传超过 9 张）；
4. 打开「急出」开关，观察提示；
5. 标题输入含「代考」内容后提交，观察违规拦截弹窗；
6. 修正标题后正常提交成功。

**验收点**：
- [ ] 三步步骤条随流程高亮推进，可回退修改且数据不丢失
- [ ] 图片上传最多 9 张，超出时拦截并提示；支持删除已选图重传
- [ ] 必填缺失（标题/价格/成色/图片等）逐项在对应字段下方红字提示，定位到首个错误
- [ ] 价格为非法值（负数/非数字）时校验拦截
- [ ] 急出开关打开时提示「急出商品最多同时 3 件」（或同等文案）
- [ ] 标题含「代考」时模拟 9001 违规拦截弹窗（展示违规原因，阻断提交）
- [ ] 提交成功有反馈并跳转（我的商品/详情页），失败有错误提示可重试

## U12 我的商品（pages/my-products/my-products）

**页面元素**：三 tab 分栏（在售 / 已售 / 下架）、商品卡片操作按钮（下架、标记已售、重新上架）。

**操作步骤**：
1. 进入我的商品页，切换三个 tab；
2. 在「在售」tab 对某商品点击「下架」，确认后观察列表变化；
3. 在「在售」tab 点击「标记已售」，进入 U13 弹窗流程；
4. 在「下架」tab 对某商品点击「重新上架」。

**验收点**：
- [ ] 三 tab 分栏数据正确隔离，tab 切换有各自的空态/加载态
- [ ] 在售商品有「下架」与「标记已售」操作，下架需二次确认
- [ ] 下架成功后该商品从在售列表移除并出现在下架 tab
- [ ] 下架 tab 商品有「重新上架」操作，成功后回到在售 tab
- [ ] 各操作失败时有错误提示，列表状态不回错乱
- [ ] 无商品时各 tab 展示对应空态与引导（去发布）

## U13 标记已售弹窗（我的商品页内组件）

**页面元素**：标记已售弹窗（买家选择列表/select 控件、确认/取消按钮、拦截提示）。

**操作步骤**：
1. 在售商品点击「标记已售」打开弹窗；
2. 不选择任何买家直接点「确认」；
3. 选择一个买家后再点「确认」；
4. 点「取消」关闭弹窗。

**验收点**：
- [ ] 未选择买家时确认被拦截，提示「必须指定买家」，弹窗不关闭、不发请求
- [ ] 选择买家后确认可提交，select 事件正确回传所选买家 id 给父页面
- [ ] 标记成功后商品从在售 tab 移至已售 tab，详情页进入 sold 遮罩态
- [ ] 取消/点击遮罩可关闭弹窗，已选状态处理符合预期（重置或保留有明确行为）
- [ ] 买家列表为空时展示空态提示，确认按钮不可用
