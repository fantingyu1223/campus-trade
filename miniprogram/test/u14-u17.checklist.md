# U14-U17 联调清单（沟通与交易 / 订单与履约）

> 环境：微信开发者工具，Mock 模式（USE_MOCK=true）。接口就绪后置 false 复测。
> 关联模块：PIM-BC-03 沟通与交易、PIM-BC-04 订单与履约。

## U14 会话列表页（pages/chat-list）

**页面元素**：安全提示以外的会话条目（对方昵称、身份标识小标、未读数 badge、最后消息摘要、相对时间）；空态；加载态；错误态（点击重试）。

**操作步骤**：
1. 进入「消息」tab / 直接打开 pages/chat-list。
2. 观察列表排序与每条会话的未读数、时间显示。
3. 点击会话条目进入 U15 会话页，随后返回列表。

**验收点**：
- [ ] 会话条目包含对方昵称、最后消息摘要、未读数 badge（未读>0 时显示数字）、相对时间（刚刚/N分钟前/N小时前/昨天/MM-DD）
- [ ] 认证商家会话显示身份标识小标（F33-AC1），与个人闲置可区分
- [ ] 会话按最后消息时间倒序排列
- [ ] 无会话时显示空态文案
- [ ] 接口失败时显示错误态且「点击重试」可重新加载

## U15 会话页（pages/chat）

**页面元素**：常驻安全提示条；消息气泡（己方右绿/对方左白）；已读/未读标记；「加载更早」；输入栏与发送按钮；风险词警示弹层；交易意向卡片。

**操作步骤**：
1. 从 U14 进入会话页（携带 conv_id / nickname）。
2. 点击「加载更早」。
3. 观察己方消息「未读→已读」变化（对方 onShow 触发已读回执）。
4. 发送含风险词消息（如「先转账」），在弹层分别点「继续发送」「修改」。
5. 对意向卡片点击「接受」/「拒绝」。

**验收点**：
- [ ] 「加载更早」按游标（最小 msg_id）分页，无更早消息时 toast 提示且按钮消失
- [ ] 己方消息显示未读（橙色）/已读（灰色）两种样式
- [ ] 进入会话 onShow 触发已读回执，对方消息标记为已读、未读数清零
- [ ] 命中风险词弹出警示弹层（不拦截发送）
- [ ] 弹层「继续发送」：带 confirm_risk=true 重发并留痕（risk_level=1），消息正常上屏
- [ ] 弹层「修改」：关闭弹层，原文保留在输入框，不发送
- [ ] 意向卡片显示价格/地点/时间，「接受」后状态变 confirmed 并 toast，可跳 U16；「拒绝」后状态变 rejected
- [ ] 加载失败显示错误态，「点击重试」可恢复

## U16 付款页（pages/pay）

**页面元素**：订单摘要卡（商品图占位/标题/金额/卖家昵称）；付款提示条；「去支付」按钮；付款强制风险确认弹层（规则列表、「我已阅读并理解」复选框、确认并支付/再想想按钮）。

**操作步骤**：
1. 带 order_id（或 product_id）进入付款页，确认摘要卡数据。
2. 点「去支付」唤起强制弹层。
3. 未勾选复选框直接点「确认并支付」。
4. 勾选「我已阅读并理解」后点「确认并支付」。
5. 重新唤起弹层点「再想想」。

**验收点**：
- [ ] 摘要卡正确展示商品图（无图时占位）、标题、金额、卖家昵称
- [ ] 弹层文案完整：平台不托管资金/取消规则/48h 自动确认/现场拒收留痕/纠纷协调说明
- [ ] 未勾选「我已阅读并理解」时确认按钮禁用（点击 toast 提示）
- [ ] 点遮罩不关闭弹层（强制确认）
- [ ] 勾选后可支付：toast「支付成功」并 wx.redirectTo 到 /pages/order-detail/order-detail?order_id=xxx
- [ ] 「再想想」关闭弹层返回摘要页，不发起支付

## U17 订单详情页（pages/order-detail）

**页面元素**：五态步骤条；48h 倒计时条；订单信息卡（订单号/商品/金额/卖家/交货地点时间）；状态化操作按钮组；订单事件 timeline。

**操作步骤**：
1. 从 U16 支付成功跳转或 U17列表 点击进入详情。
2. 观察五态步骤条当前态样式。
3. 观察 pending_confirm 态倒计时秒级跳动直至（可调短 Mock deadline 验证）超时。
4. 分别在 pending_confirm / pending_delivery / completed 态查看按钮渲染。
5. 点「确认收货」「取消订单」「现场拒收」，观察状态与 timeline 变化。
6. completed 态点「去评价」、点「申诉」。

**验收点**：
- [ ] 五态步骤条展示：待交货/待确认/已完成/已取消/申诉中，当前态高亮、加粗、变色（绿）
- [ ] pending_confirm 态显示 48h 倒计时，HH:MM:SS 每秒更新
- [ ] 倒计时 ≤0 显示「已超时」（红色样式），定时器停止；离开页面 onUnload 清理定时器无泄漏
- [ ] pending_confirm 渲染：确认收货 + 取消订单 + 现场拒收
- [ ] pending_delivery 渲染：取消订单
- [ ] completed 渲染：去评价（占位 toast「评价功能即将上线」）
- [ ] 非 appealing/cancelled 态显示「申诉」入口（占位 toast）
- [ ] 确认收货后状态 →completed，倒计时消失；取消/拒收后 →cancelled
- [ ] 每次操作向 timeline 追加「时间+事件」留痕记录

## U17列表 订单列表页（pages/order-list）

**页面元素**：订单卡片（状态标签五色、商品标题、金额、创建时间、对方昵称）；空态；加载态；错误态。

**操作步骤**：
1. 进入订单列表页，观察五色状态标签与排序。
2. 点击订单卡片进入 U17 详情。
3. 切换 Mock 空数组验证空态。

**验收点**：
- [ ] 状态标签五色区分：待交货蓝 / 待确认橙 / 已完成绿 / 已取消灰 / 申诉中红
- [ ] 每条展示商品标题、金额、创建时间、对方昵称
- [ ] 按创建时间倒序
- [ ] 点击 wx.navigateTo 到 /pages/order-detail/order-detail?order_id=xxx
- [ ] 无订单显示空态「还没有订单，去逛逛吧」
