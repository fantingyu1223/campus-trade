## U20 举报提交页（pages/report-submit/report-submit）

### 页面元素
- 举报对象信息条（对象类型标签 + 对象标题，由 report-form 承载）
- **匿名保护提示卡**：「你的举报身份对被举报方不可见」
- report-form 复合表单：理由 picker / 补充描述 textarea（≤500 计数）/ 凭证上传
- 提交成功回执页（回执编号 report_id 占位 + 状态「已受理」）

### 操作步骤
1. 带参进入：`/pages/report-submit/report-submit?target_type=product&target_id=1&target_title=测试商品`。
2. 不带 target_type 或传非法值进入 → toast「举报对象缺失」并自动返回。
3. 不选理由直接提交 → 提示「请选择举报理由」；理由选「诈骗」，描述留空提交 → 提示「请填写补充描述」。
4. 描述输入超 500 字 → 截断且计数停在 500/500。
5. 凭证连选至 9 张后再点「+」→ toast「最多上传 9 张」；点角标「×」可删除。
6. 填齐后提交 → toast 成功，进入回执页。

### 验收点
- [ ] 举报对象信息条正确展示类型标签与标题
- [ ] **匿名保护提示卡常驻可见，文案为「你的举报身份对被举报方不可见」**（F18-AC2）
- [ ] **理由枚举仅四项：诈骗 / 违禁品 / 虚假描述 / 其他，不可自由输入**（F18-AC1）
- [ ] 描述 ≤500 字实时计数，超限截断
- [ ] **凭证上传 ≤9 张，超限拦截提示，支持删除**
- [ ] 理由未选 / 描述为空时不发起提交，提示明确
- [ ] 提交成功后回执页展示 report_id（占位）与状态「已受理」
- [ ] 回执页含匿名保护说明文案

## U21 申诉提交页（pages/appeal-submit/appeal-submit）

### 页面元素
- 处罚记录引用条（类型 / 时间 / 原因，Mock 数据）
- 申诉类型 picker：卖家失联 / 错标已售 / 货不对板 / 误封复核
- 申诉理由 textarea（≤500 计数）
- 凭证上传（≤9 图 + 删除）
- **48h 时限提示条**：「运营将在 48 小时内介入处理」
- 提交成功回执页

### 操作步骤
1. 进入页面（可带 punish_id 参数），核对处罚记录引用条展示。
2. 不选类型直接提交 → 提示「请选择申诉类型」；理由为空提交 → 提示「请填写申诉理由」。
3. 理由输入超 500 字 → 截断。
4. 凭证上传至 9 张后再选 → 拦截提示；可删除。
5. 提交 → toast 成功，进入回执页（回执编号 + 状态「已受理」）。

### 验收点
- [ ] 处罚记录引用条展示类型 / 时间 / 原因三项
- [ ] 申诉类型 picker 恰为四项枚举，选「误封复核」时 appeal_type=punishment，其余为 dispute
- [ ] 理由 ≤500 字实时计数
- [ ] 凭证 ≤9 张，支持删除
- [ ] **48h 时限提示条常驻可见**（F30-AC1），回执页文案同样含 48h 口径
- [ ] 类型未选 / 理由为空时不发起提交
- [ ] 提交成功后回执页展示 appeal_id 占位与状态「已受理」

## U24 我的页面（pages/my/my）

### 页面元素
- 用户信息卡：头像占位 / 昵称 / identity-badge 身份标识
- **merchant-badge 强化标识**（identity_type==='merchant' 时展示，金色边框 + 图标，比 identity-badge 更醒目）
- 功能列表：我的商品 / 我的求购 / 我的收藏 / 我的订单
- 「账号与安全」分组 + 「注销账号」红色入口
- 注销二次确认弹窗（cancel-account-modal）
- 已注销终态（「已注销，感谢使用」）

### 操作步骤
1. 进入页面，核对用户信息卡与商家标识展示。
2. 依次点四个功能项，确认 wx.navigateTo 跳转正确页面。
3. 点「注销账号」→ 弹窗弹出，核对警告文案。
4. 输入框随意输入 → 确认按钮禁用；输入「注销」二字 → 按钮可用。
5. （mockBlocked=false）确认 → 进入「已注销，感谢使用」态，可回登录页。
6. 改 `data.mockBlocked = true` 重复步骤 3-5 → toast「存在未完成交易，请先完结后再注销」，弹窗关闭，页面不变。

### 验收点
- [ ] 头像占位符 / 昵称 / identity-badge 正确展示
- [ ] **merchant 用户额外展示 merchant-badge 金色强化标识，非 merchant 不展示**（F33-AC1）
- [ ] 四个功能项跳转正确：my-products / want-buy / favorites / order-list
- [ ] 「注销账号」为红色入口，位于「账号与安全」分组
- [ ] **弹窗警告文案含「注销后不可恢复，存在在途交易将被拦截」**（F26-AC1）
- [ ] **二次确认必须输入「注销」二字，否则确认按钮 disabled / 点击提示**
- [ ] **mockBlocked=false 分支：确认后展示「已注销，感谢使用」终态**
- [ ] **mockBlocked=true 分支（在途拦截）：toast「存在未完成交易，请先完结后再注销」**
- [ ] 取消 / 遮罩点击可关闭弹窗且不触发注销
